# Bocholt erleben – AI Brand Lab / Richtungs-Gate

Status: qualifizierte Richtungsstudie, kein öffentlicher Markenmaster.

Dieses Verzeichnis gehört zu GitHub-Issue #224. Es enthält zwei Richtungen, die nach einer breiten internen AI-Exploration die dokumentierte Mindestqualität erreicht haben.

## Öffnen

`index.html` lokal im Browser öffnen. Alle SVGs, Styles und Inhalte liegen repository-lokal.

## Richtungen

- **A – Offene Fenster:** eigenständig konstruierte B-Silhouette mit zwei offenen Inhaltsräumen.
- **B – Momentmarker:** wortmarkengeführtes System mit einem asymmetrischen Marker für kuratierte Empfehlungen.

## Grenzen

- keine öffentliche oder technische Produktänderung;
- keine rechtliche Markenfreigabe;
- keine Behauptung vollständiger Einzigartigkeit;
- keine externen Designer oder Stockgrafiken;
- Fonts wurden nur zum Erzeugen von Vektorpfaden verwendet und werden nicht verteilt.
