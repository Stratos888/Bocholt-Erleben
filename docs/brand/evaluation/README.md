# Brand Evaluation Evidence

Dieses Verzeichnis definiert den verbindlichen Evidenzrahmen für spätere Markenrichtungen.

## Zweck

Der Rahmen verhindert, dass Produzent, Score und Validator eine zirkuläre Qualitätsbehauptung erzeugen.

CI darf nur bestätigen:

- erforderliche Evidenz ist vorhanden;
- Rollen sind getrennt;
- Blindheit und Reihenfolge sind dokumentiert;
- Knock-outs wurden vor Scores geprüft;
- Formeln und Mindestwerte wurden korrekt angewandt;
- technische Pass/Fail-Nachweise sind vollständig.

CI darf keine ästhetische Qualität zertifizieren.

## Ablauf je späterem Kandidaten

1. anonyme ID nach Muster `candidate-000`;
2. Produzentendokumentation ohne finalen Designscore;
3. Originalgrößen-Evidenz;
4. unabhängige Kritik A;
5. unabhängige Kritik B;
6. Red-Team-Prüfung;
7. Konsolidierung nur ohne Knock-out;
8. technische Pass/Fail-Prüfung;
9. gegebenenfalls Product-Owner-Präsentation.

## Vorlagen

- `templates/producer.json`
- `templates/critic-a.json`
- `templates/critic-b.json`
- `templates/red-team.json`
- `templates/consolidation.json`

Die Vorlagen sind keine echten Bewertungen und dürfen nicht als Kandidatenevidenz ausgegeben werden.
