# Phase 4 – Anonyme Produzentenexploration

Workpack: #256

Dieser Pfad enthält zwölf strukturelle Explorationssysteme und getrennte Blindkritik-Pakete.

## Dateien

- `blind-systems.json`: ausschließlich anonyme IDs und drei repository-lokale SVG-Payloads je System;
- `producer-manifest.json`: Architekturklassen und Konstruktionsfamilien, nur für den Produzenten;
- `critic-a.html`: Form, Monochrom und Originalgrößen;
- `critic-b.html`: identische Produkt- und Kategorieanwendungen;
- `red-team.html`: Knock-out-Suche mit Genericity-Ablationen;
- `producer-board.html`: interne Konstruktionsübersicht;
- `prompts/`: getrennte Chat-Aufträge.

## Grenzen

- keine Scores;
- keine Rangfolge;
- keine Finalisten;
- keine Freigabe;
- keine öffentliche Produktänderung;
- SVGs sind strukturelle Exploration, keine finalen Produktionsmaster.

Blindkritik-Chats erhalten ausschließlich ihre Prüffläche und ihren Prompt.
